# mic-live

按一下就聽到麥克風的聲音，再按一下暫停。沒有畫面、沒有錄音、不會上傳。

給長輩用的版本：字大、按鈕大、用語白話，設定記在瀏覽器裡，關掉再開也不會不見。

## 用法

1. 打開 <https://chiuhuang.github.io/mic-live/>，或在本機跑 `python -m http.server 8080`。
2. 按中間那顆大按鈕，第一次會問你要麥克風權限，選「允許」。
3. 再按一下就暫停。

**請戴耳機。** 不戴耳機的話麥克風會聽到自己發出的聲音，然後尖叫。

網址必須是 `https://` 或 `http://localhost`，瀏覽器才會給麥克風權限（`file://` 不行）。

## 設定

右上角的齒輪。每一項都會即時生效，並存在瀏覽器的 localStorage（鍵名 `mic-live.settings.v1`），不用按儲存。

| 項目 | 說明 |
| --- | --- |
| 用什麼方式聽 | 「戴耳機」＝原音、不做處理；「麥克風和喇叭」＝開回授抑制（見下面） |
| 聲音大小 | 喇叭出來的大小，0 到 150%（喇叭模式下最多 85%，見下面） |
| 麥克風靈敏度 | 麥克風太小聲時調高，0 到 200% |
| 使用哪個麥克風 | 麥克風超過一個時可以選；沒拿到麥克風權限前只能看到「麥克風 1、2…」 |
| 聲音從哪裡出來 | 輸出裝置（iPhone 喇叭 / 藍牙喇叭…）。麥克風和輸出可以分開選 |
| 沒人講話時自動靜音 | 門檻跟著量到的噪聲地板走（不是固定 dB），吵的環境才關得住 |
| 顯示音量條 | 在按鈕下面顯示一條音量條 |
| 測試聲音 | 送一段 440 Hz 走整條輸出線路，出聲就代表輸出段沒問題 |
| 除錯資訊 | 頻譜圖 + 演算法每一步的數字（見下） |
| 畫面顏色 | 跟著系統 / 淺色 / 深色 |
| 還原成預設值 | 把上面全部改回預設 |

## 除錯資訊

設定裡的「除錯資訊」會開一個全螢幕視圖，對著麥克風講話就看得到：

- **頻譜圖**（對數刻度 50 Hz - 20 kHz）。黑線 = 演算法正在盯的那一根；
  紅線 = 已經被壓掉的頻率（旁邊標出編號和 Hz）；紅虛線 = -25 dB 的搜尋門檻。
- **最高頻率** — 整個頻譜最高的那一根（通常是你的基頻，演算法不會碰它）
- **演算法目標** — 只在 450-11000 Hz 範圍內最高的那一根，也就是演算法實際會下手的那個
- **背景 / 比背景高 / 鄰近最高 / 分離度** — 四個判斷用的數字，括號裡是門檻
- **演算法判斷** — 「不通過：不夠突出、旁邊有別的峰（諧波）」之類，紅色代表它要動手
- **收聲 / 慢速平均 / 掃描次數 / AudioContext 狀態**
- **四顆濾波器**各是什麼狀態（Hz / dB / Q），沒用到就寫「未使用」

這是為了不必靠猜：唱一個音，看那四個數字，就知道它為什麼抓你或為什麼放過你。

存壞掉的 localStorage（例如有人手改成 `"master":"loud"`）不會讓頁面壞掉，會安靜地退回預設值。

切換模式不會重新申請麥克風權限，因為濾波器一直在音訊圖裡，模式只是改參數。

## 自動靜音跟著噪聲地板走

固定 −55 dB 的門檻在吵的環境裡等於沒有門檻：手機麥克風在有背景噪音的地方量到
−19 dB，那個門檻永遠不會關閉，於是整個環境噪音就直接從喇叭出來，你只聽得到噪音。

現在改成自己量地板：把最近 96 幀（約 1.6 秒）的音量做第 10 百分位當作地板。
講話中間一定有低點，所以地板不會被你的聲音帶走，而安靜的時候一秒多就收斂。
門檻是「比地板高 10 dB 開、比地板高 4 dB 關」，除錯視圖裡看得到地板和門檻。

## 輸出裝置

麥克風和輸出可以分開選（`AudioContext.setSinkId`）。兩個限制要講清楚：

- **iPhone / iPad 的 Safari 沒有 `setSinkId`**。那種情況選單會停用，並寫「請到手機的
  控制中心（或設定 → 藍牙）切換」——而不是給一個按了沒反應的選單。
- 輸出選項在拿到麥克風權限之前沒有名字（瀏覽器的隱私限制），所以第一次開啟設定時
  可能只看到「輸出 1、輸出 2」。

換輸出會寫在 localStorage，並且在每次開始播放時重設一次 —— 新的 `AudioContext`
一定從系統預設輸出開始，忘了重設就會發現設定沒生效。

## 回授抑制（麥克風和喇叭同時開）

麥克風離喇叭只有十幾公分，喇叭播出來的聲音又回到麥克風，迴路增益只要超過 1 就會尖叫。
要完全根治只有一個辦法：戴耳機（或把麥克風拿遠）。沒戴耳機時，這裡用四層把它壓下來，
全部只改參數、不重建音訊圖，所以不會有跳聲：

1. **音量上限壓在 85%** — 讓電子增益的回授餘裕留在 1 以下，最便宜也最有效的一層。
2. **切掉兩端** — 高通 180 Hz（喇叭自己的低頻最容易被聽回去）、低通 6.5 kHz
   （回授的第一個模式幾乎都在 1-4 kHz，砍掉就大幅提高起振門檻）。
3. **限幅** — `DynamicsCompressor`，threshold -3 dB、ratio 20，讓音量到不了無限增長。
4. **兩層偵測**：
   - *音量層*：麥克風音量比慢速平均（時間常數 2.5 秒）高 8 dB 以上時，立刻把輸出收 14 dB，
     接著慢慢回來。用音量偵測而不是等頻譜，是因為回授起頭比陷波器反應快。
     人聲突然大聲也會被收一點，這是這一層的代價。
   - *頻譜層*：回授在頻譜上是一根「又高、又窄、左右三分之一個八度內沒有東西、而且持續
     0.4 秒以上」的尖峰。每 3 幀掃一次（4096 点 FFT，約 20 次/秒），用前綴和算每個 bin
     左右各 24 個 bin（扣掉峰本身）的平均功率當背景，要求：
     - 比背景高 20 dB 以上
     - 左右三分之一個八度內沒有高於它 15 dB 的峰（人聲的共振峰一個接一個、諧波到處都是，
       回授只有孤零零一根）
     - 只在 450 Hz 以上找（人聲基頻 85-255 Hz，低於 450 Hz 的諧波不管）
     - 麥克風音量要大於 -25 dBFS 才值得找
     然後把一個 peaking 濾波器（-14 dB，Q 6-25）拉過去，連續 6 次不見就放掉。四個循環使用，
     沒用到的 gain = 0，數學上完全透明。

     **踩過的坑**：背景功率一開始寫成 `power[i+3] - power[i-2] + power[lo] - power[hi-1]`，
     後面兩項相減是負的，背景永遠算成 -120 dB，於是「比背景高 12 dB」這個判斷形同虛設，
     偵測器變成「任何持續的峰都挖」。結果就是只聽得到很尖的雜訊、聽不到人聲 ——
     共振峰被一個又一個濾波器削掉了。

`echoCancellation` 在兩種模式下都關著。瀏覽器的回聲消除會把你正在聽的聲音當成回聲消掉，
對「監聽自己」這件事是反效果，這裡自己處理比較可靠。

## 音訊怎麼接的

```
MediaStreamSource -> 麥克風靈敏度 -> 高通 -> 低通 -> AnalyserNode -> 自動靜音 -> 限幅 -> 陷波 x4 -> 聲音大小 -> 輸出裝置 -> 喇叭
```

高通、低通、限幅、四個陷波器永遠都在線路裡，「戴耳機 / 麥克風和喇叭」只是改參數，
所以切換模式不用重開麥克風，也不會跳聲。

- 中間沒有任何 buffer 或工作佇列，延遲就是瀏覽器音訊堆疊的延遲（桌機約 10-30 ms）。
- `echoCancellation` / `noiseSuppression` / `autoGainControl` 全部關掉，監聽自己時這三個只會礙事。
- 音量計用 `getFloatTimeDomainData` 而不是 byte 版，byte 版在 -48 dB 以下會全部變成 0。
- 暫停時不丟掉 stream，只把音量降到 0 並讓 track 停止收音，所以恢復時不會再跳一次權限提示。
- 關掉分頁（`pagehide`）會 `track.stop()` 把麥克風還回去，不然麥克風的指示燈會一直亮著。

## PWA

可以加到主畫面當成一個 App 用，離線也開得起來。

- `manifest.webmanifest` — 名稱、圖示（any + maskable）、`display: standalone`
- `sw.js` — 預先抓 `index.html` / mdui / 圖示。頁面導覽先走網路再退回快取，
  靜態檔用 stale-while-revalidate。改了 `sw.js` 裡的 `VERSION` 就是一次新快取。
- 圖示是 `tools/make-icons.cjs` 算出來的（只用 Node 內建的 zlib 手寫 PNG 編碼器，
  圖形用 signed distance field 畫），要改樣式改那支腳本重跑就好：

```powershell
node tools\make-icons.cjs
```

`start_url` 和 `scope` 用相對的 `.`，所以 GitHub Pages 的子路徑 `/mic-live/` 也不會壞。
瀏覽器說可以安裝時會跳一次提示（長輩不會自己找「加入主畫面」）。

## 目錄

```
index.html               整個網站，單一檔案
manifest.webmanifest     PWA 設定
sw.js                    離線用
favicon.svg              分頁圖示
icons/*.png              PWA 圖示（由 tools/make-icons.cjs 產生）
tools/make-icons.cjs     圖示產生器
vendor/mdui.css          mdui 2.1.5（MIT）
vendor/mdui.global.js
```

mdui 直接放在 `vendor/`，不連 CDN，也不需要圖示字型：按鈕圖示是內嵌 SVG，
`mdui-switch` 和 `mdui-select` 的內建圖示都傳空字串拿掉，所以沒有字型載入失敗就變成
一串英文的問題。
